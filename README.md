# Коммерческая деятельность — интерактивная викторина

Соревновательная учебная викторина для занятий. Студенты подключаются по QR-коду, вводят фамилию и имя, отвечают на вопросы и в реальном времени видят свои очки и место в рейтинге. Преподаватель управляет игрой через отдельную админ-панель и выводит лидерборд на большой экран.

## Возможности

- подключение студентов по QR-коду или коду комнаты;
- общий рейтинг в реальном времени;
- очки за правильный ответ, скорость и серию правильных ответов;
- анимации правильного и неправильного ответа, конфетти и бонусы;
- большой экран с «гонкой лидеров» и финальным пьедесталом;
- админ-панель: создание комнат, запуск вопросов, переход вперёд/назад;
- ручное начисление и снятие баллов с указанием причины;
- хранение комнат, участников и ответов в Cloudflare D1.

## Рабочая версия

[Открыть викторину на GitHub Pages](https://poddon.github.io/opp-quiz/)

Админ-панель открывается кнопкой «Администратор». Большой экран комнаты запускается из панели управления. Статический мобильный интерфейс размещён на GitHub Pages, а API комнат и рейтинга работает на серверной части Sites.

## Запуск проекта

Требуется Node.js 22.13+ и pnpm.

```bash
pnpm install
pnpm dev
```

## Переменные окружения

```env
ADMIN_PASSWORD=your_admin_password
SESSION_SECRET=your_long_random_secret
PUBLIC_SITE_URL=https://your-domain.example
```

`PUBLIC_SITE_URL` используется для формирования абсолютной ссылки внутри QR-кода.

## Технологии

- React / Next.js-compatible App Router через Vinext;
- TypeScript и Tailwind CSS;
- Cloudflare Workers и D1;
- Drizzle ORM;
- генерация QR-кодов библиотекой `qrcode`.

Не добавляйте `.env.local` и реальные пароли в репозиторий.
