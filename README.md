## Битва коммерсантов · живая викторина (Модуль 3)

- Ученики: https://poddon.github.io/opp-quiz/live/ — сканируют QR, вводят фамилию и имя.
- Экран ведущего: https://poddon.github.io/opp-quiz/live/screen.html (вход admin). Пробел — следующий шаг.
- Пульт на телефоне: https://poddon.github.io/opp-quiz/live/screen.html?pult=1
- Ход игры ведёт преподаватель: практика → вопрос с таймером → правильный ответ → рейтинг → итоги.
- Очки: до 1000 за верный ответ (быстрее — больше), +100 за каждый верный подряд (до +500).
- Связь через публичные MQTT-брокеры, сервер не нужен. Очки хранятся в браузере экрана ведущего.
- Вопросы и штрафы: `live/questions.js`.
