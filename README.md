## Битва коммерсантов · живая викторина (Модуль 3)

Викторина разделена на две независимые комнаты. Списки участников, очки, ход занятия и управление не пересекаются.

### Учебный класс 1
- Студенты: https://poddon.github.io/opp-quiz/live/?room=class1
- Экран преподавателя: https://poddon.github.io/opp-quiz/live/screen.html?room=class1
- Пульт на телефоне: https://poddon.github.io/opp-quiz/live/screen.html?room=class1&pult=1

### Учебный класс 2
- Студенты: https://poddon.github.io/opp-quiz/live/?room=class2
- Экран преподавателя: https://poddon.github.io/opp-quiz/live/screen.html?room=class2
- Пульт на телефоне: https://poddon.github.io/opp-quiz/live/screen.html?room=class2&pult=1

- У каждого класса свой QR-код на экране ведущего, ведущий может переключить класс сверху.
- Номера заданий соответствуют слайдам презентации (51 слайд).
- Старые ссылки без параметра комнаты открывают класс 1.
- Логин и пароль ведущего отключены, доступ по прямой ссылке без защиты.
- Данные каждого класса сохраняются отдельно в браузере компьютера ведущего (если очистить данные браузера, локальные результаты могут исчезнуть).
- Связь через публичные MQTT-брокеры, для проведения двух занятий одновременно откройте отдельный экран ведущего для каждого класса.
- Очки: до 1000 за верный ответ (быстрее — больше), +100 за каждый верный подряд (до +500).
- Вопросы и штрафы: `live/questions.js`.
