# Локальный запуск викторины в корпоративной Wi-Fi сети

Этот режим бесплатный: ноутбук ведущего раздаёт страницу и обмен ответами по локальной сети. VPN и внешний MQTT-сервис не используются.

## Что нужно

- Windows-ноутбук, подключённый к той же корпоративной Wi-Fi сети, что и телефоны студентов.
- Node.js LTS (версия 18 или новее): https://nodejs.org/
- Папка репозитория целиком: сервер ищет страницу в соседней папке `live`.

## Запуск

1. Скачайте репозиторий как ZIP через GitHub: Code → Download ZIP, затем распакуйте его.
2. Установите Node.js LTS, если он ещё не установлен.
3. Откройте папку `lan-server` и запустите `start.bat`.
4. Если Windows спросит о брандмауэре, разрешите доступ в частной/корпоративной сети (если политика организации позволяет).
5. В чёрном окне появятся IP-адреса и ссылки. Откройте ссылку «Экран ведущего 1» на ноутбуке и покажите QR студентам. Для второго класса откройте ссылку «Экран ведущего 2».
6. Не закрывайте окно сервера, пока идёт занятие.

## Важно

- Все устройства должны находиться в одной сети, доступной друг для друга.
- Если телефоны не открывают адрес, попросите IT проверить изоляцию Wi-Fi-клиентов и разрешить входящие подключения TCP на порт 8080 от устройств учебного класса.
- Не публикуйте порт 8080 в интернете и не используйте этот сервер для публичных сетей: авторизация здесь не настроена.
- Результаты живут в браузере экрана ведущего; экспортируйте CSV перед очисткой данных браузера.
- Для работы внутри LAN не нужен доступ к внешнему MQTT-брокеру. Внешние Google Fonts могут не загрузиться без интернета, но интерфейс использует системные резервные шрифты.
